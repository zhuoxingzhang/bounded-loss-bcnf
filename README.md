# Boyce-Codd Normal Form with Bounded Dependency Loss: code and experiments

This repository holds the implementation of the algorithms `Drop` and `Repair` of the paper
"Boyce-Codd Normal Form with Bounded Dependency Loss", the brute-force oracles that back its negative
results, the validation scripts, the FD sets of the experiments, and the experiment driver.

Everything is plain Python 3 (tested with 3.12) and uses only the standard library.

## Layout

| path | content |
|---|---|
| `fdlib.py` | attribute closure (linear), minimal keys (Lucchesi-Osborn), atomic cover Σ_a (all minimal FDs, via the minimal keys of Σ + A→R per attribute A), violators and critical minimal FDs, enforceability test (Theorem 3.17), BCNF design from an enforceable set (schemata of the uncritical minimal FDs, merged while BCNF holds, plus a key schema, redundant schemata removed), key dependencies, dependency loss, local enforcement, tableau chase, minimal cover, 3NF synthesis (BCNF whenever possible), classical BCNF decomposition, loaders for the FD files |
| `drop.py` | `Drop(R, Σ, w)` (Algorithm 1). The sets Δ are generated by a tree search: a node Δ computes *requirement sets*, sets of minimal FDs of which every closed choice above Δ that satisfies the cover condition (Lemma 5.3) must contain one (the FDs that fire in a derivation of an element of Δ from Σ_a − Δ; for a critical minimal FD g = Y→B that U ∪ C(Δ) ∪ Δ does not imply, the critical minimal FDs with left-hand side inside Y⁺ and the violators of their schemata). The search branches over the smallest requirement set, prunes with the packing bound of pairwise disjoint requirement sets, and uses iterative deepening on the weight, so the first feasible candidate is optimal. A candidate is tested by a goal-directed, complete search for the weakened FDs W (iterative deepening on \|W\| up to `max_w`). The result reports whether the loss is proved minimal (`exact`), a certified lower bound, and otherwise a greedy plain design with randomised restarts. `drop_plain` is the plain enumeration of the closed choices by increasing weight, kept for cross-checks |
| `repair.py` | `Repair(R, Σ, w)` (Algorithm 2): 3NF synthesis that is BCNF whenever possible, key dependencies of the BCNF schemata, local `Drop` on every critical schema, one enforceability test of the assembled set Γ, fallback to the global `Drop` |
| `validate_fdlib.py` | cross-checks the symbolic layer against the brute-force oracles on random instances (atomic cover, enforceability, keys, `Drop` loss = λ, designs sound and locally enforced, unenforced set = Δ, `Repair` ≥ λ) |
| `test_examples.py` | the schemata of the paper with their proved losses |
| `experiments.py` | experiment E1 on the FD sets in `data/fds`; every FD set runs in its own process with a timeout; results in `results/e1.jsonl`, `--table` prints the table |
| `minloss_bruteforce.py`, `weak_stats.py` | the brute-force layer: closure tables of size 2^n, enumeration of the closed FD sets, exact λ, level-wise exact solver (schemata with at most about seven attributes) |
| `cand*_stats.py`, `p6*_stats.py`, `wmin_*.py`, `targeted_search*.py`, `gadget_try.py`, `price_stats.py`, `undrop_stats.py`, `mech_inspect.py`, `sample_kc.py`, `search4.py`, `verify_kc_gap*.py`, `kc_inspect.py` | the random and exhaustive searches behind the negative results and the conjecture tests of the paper; their logs are the `*.log` files next to them (the four largest logs are not in the repository) |
| `data/fds` | the FD sets of the experiments (see below) |
| `results` | the records written by `experiments.py` |

## Reproducing

```bash
python test_examples.py            # the examples of the paper (seconds)
python validate_fdlib.py 5 600 11  # random five-attribute instances against the brute force for 600 s, seed 11
python validate_fdlib.py 6 900 12  # six attributes
python experiments.py              # E1 on all FD sets, one process per set; then
python experiments.py --table      # the table of results/e1.jsonl
python experiments.py --one abalone
```

Validation status: with the plain enumeration, 44,943 five-attribute and 21,156 six-attribute random instances
without failure (`validate_n5.log`, `validate_n5b.log`, `validate_n6b.log`); with the tree search and the final
`Repair`, 300,322 five-attribute and 73,730 six-attribute random instances without failure (`validate_n5e.log`,
`validate_n6d.log`; earlier runs `validate_n5c.log`, `validate_n5d.log`, `validate_n6c.log`).

## Data

`data/fds/complete` and `data/fds/null-equality` hold the minimal FDs discovered by Metanome on the data sets of
the HPI repeatability page (JSON: `{"R": n, "fds": [{"lhs": [...], "rhs": [...]}]}`; attributes are column
indices), on complete data (abalone, adult, fd-red, letter, lineitem) and on incomplete data under the null
equality interpretation (breast, bridges, china_weather, diabetic, echo, hepatitis, ncvoter, pdbx, uniprot).
`data/fds/tpch` holds the FDs of the eight TPC-H tables in the Metanome text format. The discovery output for
orders omits the FD with empty left-hand side of the constant column o_shippriority, which we added as the last
line `->5` of `orders-fds.txt`. The discovered sets are
complete sets of minimal FDs: on every set with at most 758 FDs the computed atomic cover equals the input, and
above 2,000 input FDs `experiments.py` takes the input as Σ_a after checking that every left-hand side is minimal
(marked `+` in the table).
